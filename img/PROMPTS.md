## Conversion Notes

- Target format: WebP
- Character portraits: 512×768px, max 80KB each
- Character thumbs: 64×64px, max 8KB each
- District art: 256×192px, max 20KB each
- District thumbs: 48×48px, max 5KB each
- Backgrounds: 1920×1080px, max 150KB each (WebP with aggressive compression)
- UI icons: keep as SVG (final vector quality, no conversion needed)
- After converting all assets: change `IMG_EXT` in `js/data.js` from `'svg'` to `'webp'`
- Test by opening `index.html` and verifying all screens show images with emoji fallback working correctly
