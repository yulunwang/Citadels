# シタデル · Citadels 3D

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md)

ろうそくの灯る 3D テーブルで自分の街を築くゲームです。毎ラウンド秘密の役職を選び、ライバルの裏をかいて、最も多くの得点を目指します。最初に街を完成させた人が勝つとは限りません。

## ▶ [今すぐプレイ](https://yulunwang.github.io/Citadels/)

**https://yulunwang.github.io/Citadels/**

ダウンロードもインストールも不要で、PC でもスマートフォンでもブラウザですぐに遊べます。スマートフォンでは「ホーム画面に追加」すると、アプリのように使えます。

## 遊び方

**コンピューターと対戦：**「AIと対戦」を選び、対戦相手の人数（1〜6 人）と強さを決めて開始します。

**友達とオンライン対戦**
1. 「ルームを作る」を押すと、6 文字のルームコードが表示されます。
2. 友達は同じリンクを開き、「ルームに参加」を押してコードを入力します。
3. 空いた席は「AIを追加」でコンピューターを入れられます。全員そろったら開始です。

初めての方は、ホーム画面の「遊び方」でルールを確認できます。対局中は「ヒント」ボタンが次の一手を提案します。

## 特長

- **2〜7 人**で遊べます。一人でもオンラインでも。
- **3 段階の AI**：やさしい・ふつう・狡猾。AI は知ってよい情報しか見られず、あなたの手札や隠れた役職を覗くことはありません。
- **6 言語対応**：English、简体中文、日本語、한국어、Español、Français。🌐 メニューからいつでも切り替えられます。
- **中断しても安心**：一人プレイは自動保存。オンラインでページを再読み込みしても自動的に席に戻ります。
- **ショートカット**：G 金貨 · D カードを引く · B 建設 · A 役職の能力 · E 手番終了 · H ヒント · 1〜9 カード選択。

## 開発者向け

ビルド不要。素の JavaScript（ES モジュール）と Three.js で作られています。ローカルで動かすには：

```bash
node serve.mjs    # http://localhost:5173 を開く
```

テスト：

```bash
node test/engine.test.mjs     # ルールの自己チェック + 全言語の翻訳がそろっているか
node test/pressure.mjs 600    # 負荷テスト：公平性（AI は隠れた情報を見られない）、ランダム操作、AI の行動統計
node test/ai-duel.mjs 400     # 狡猾 対 ふつう の勝率
```

| ファイル | 役割 |
|---|---|
| `js/engine.js` | ルールエンジン：`act(state, pid, action)` と `viewFor(state, pid)`（各プレイヤーが見られる情報） |
| `js/ai.js`, `js/search.js` | コンピュータープレイヤー（`viewFor` だけを受け取る）と「狡猾」の先読み |
| `js/scene.js`, `js/models.js`, `js/materials.js` | 3D テーブル、建物モデル、マテリアル |
| `js/ui.js`, `js/lobby.js` | ゲーム画面とロビー |
| `js/main.js`, `js/net.js` | ゲーム進行、セーブ、オンライン対戦（PeerJS） |
| `js/i18n.js`, `js/lang/*.js` | テキスト：英語・中国語は `i18n.js`、その他の言語は 1 言語 1 ファイル |
| `js/data.js`, `js/sfx.js` | カードデータ、効果音 |

**言語の追加：** `js/lang/fr.js` をコピーして訳し（`{プレースホルダー}` はそのまま）、`js/i18n.js` の `LANGS` と `EXTRA` に登録します。訳し漏れがあると `node test/engine.test.mjs` が失敗します。

`main` にマージすると上のリンクに自動で公開され、プルリクエストごとにプレビュー用のリンクも作られます。
