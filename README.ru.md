Стройте свой город на 3D-столе при свечах: каждый раунд тайно выбирайте персонажа, перехитрите соперников и наберите больше всех очков. Закончить первым ещё не значит победить.

## ▶ [Играть](https://yulunwang.github.io/Citadels/)

**https://yulunwang.github.io/Citadels/**

Ничего не нужно скачивать и устанавливать: игра работает в любом браузере на компьютере и телефоне. На телефоне выберите «Добавить на главный экран» — и она будет как приложение.

## Как играть

**Против компьютера:** нажмите **Против ИИ**, выберите число соперников (1–6) и сложность, и начинайте.

**По сети с друзьями**
1. Нажмите **Создать комнату** — появится код комнаты из 6 символов.
2. Друзья открывают ту же ссылку, нажимают **Войти в комнату** и вводят код.
3. Свободные места можно заполнить кнопкой **Добавить ИИ**, затем начинайте.

Впервые играете? На главном экране есть **Правила**, а в игре кнопка **Подсказка** предложит следующий ход.

## Особенности

- **От 2 до 7 игроков**, в одиночку или по сети.
- **Три уровня ИИ:** Лёгкий, Обычный и Хитрый. ИИ знает только то, что ему положено: он никогда не видит вашу руку и скрытых персонажей.
- **11 языков:** English, 简体中文, 繁體中文, 日本語, 한국어, Español, Français, Deutsch, Português, Русский и Italiano — переключайте в меню 🌐 когда угодно.
- **Ничего не потеряется:** одиночные игры сохраняются автоматически, а при обновлении страницы в сетевой игре вы сразу возвращаетесь на своё место.
- **Клавиши:** G золото · D взять карты · B строить · A способность персонажа · E конец хода · H подсказка · 1–9 выбрать карту.

## Для разработчиков

Без сборки: чистый JavaScript (ES-модули) и Three.js. Локальный запуск:

```bash
node serve.mjs    # затем откройте http://localhost:5173
```

Тесты:

```bash
node test/engine.test.mjs     # проверка правил + все языки переведены полностью
node test/pressure.mjs 600    # нагрузочный тест: честность (ИИ не видит скрытого), случайные ходы, статистика поведения ИИ
node test/ai-duel.mjs 400     # процент побед Хитрого против Обычного
```

| Файл | Назначение |
|---|---|
| `js/engine.js` | Движок правил: `act(state, pid, action)` и `viewFor(state, pid)` (что видит каждый игрок) |
| `js/ai.js`, `js/search.js` | Игроки-ИИ (получают только `viewFor`) и просчёт ходов уровня «Хитрый» |
| `js/scene.js`, `js/models.js`, `js/materials.js` | 3D-стол, модели зданий, материалы |
| `js/ui.js`, `js/lobby.js` | Игровой интерфейс и лобби |
| `js/main.js`, `js/net.js` | Ход игры, сохранения, сетевая игра (PeerJS) |
| `js/i18n.js`, `js/lang/*.js` | Тексты: английский и упрощённый китайский в `i18n.js`, по файлу на каждый другой язык |
| `js/data.js`, `js/sfx.js` | Данные карт, звук |

**Добавить язык:** скопируйте `js/lang/fr.js`, переведите тексты (сохраняя `{подстановки}`) и зарегистрируйте язык в `LANGS` и `EXTRA` в `js/i18n.js`. `node test/engine.test.mjs` упадёт, если какой-то текст или подстановка пропущены.

После слияния в `main` ссылка выше обновляется автоматически, а для каждого pull request создаётся своя ссылка для предпросмотра.
